## Variable key

<table>
  <thead>
    <tr>
      <th style={{width:"10rem"}}>Variable</th>
      <th>Source</th>
    </tr>
  </thead>
  <tbody>
    <tr><td><code>[firstName]</code></td><td><code>matchedPatient.firstName</code> → <code>collectedFields.firstName</code> → <code>"there"</code></td></tr>
    <tr><td><code>[patientName]</code></td><td><code>matchedPatient.firstName + lastName</code> → <code>"the patient"</code> / <code>"your child"</code></td></tr>
    <tr><td><code>[chiefComplaint]</code></td><td><code>visitReason.callerStatement</code> (lower-cased, period stripped)</td></tr>
    <tr><td><code>[topic]</code></td><td><code>chiefComplaint</code> → <code>SERVICE_LINE_TITLES[suggestedServiceLine]</code></td></tr>
    <tr><td><code>[fields]</code></td><td>Joined list of: name · DOB as MM/DD/YYYY · Phone as XXX-XXX-XXXX</td></tr>
    <tr><td><code>[MM/DD/YYYY]</code></td><td><code>collectedFields.dob</code> formatted as month/day/year</td></tr>
  </tbody>
</table>
