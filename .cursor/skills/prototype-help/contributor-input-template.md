# Prototype Help — Contributor Input Template

Copy into a **new** Cursor chat when you are unsure what to do. After updating UX-Projects, start a new chat so Cursor discovers the latest skills.

```text
@prototype-help

I am trying to: <describe what you need>
```

Examples:

```text
@prototype-help

I am trying to: add a prototype I already built in another folder
```

```text
@prototype-help

I am trying to: update a prototype that is already in Prototype Hub
```

```text
@prototype-help

I am trying to: figure out why @add-prototype is not showing up
```

Cursor will inspect your workspace without changing files and give you the exact next prompt to use.
